# empiresimworld
This is really a fun project to give visual representation of Empire Simulation to demonstrate how empires are evolved overtime. To buid this I have followed below steps 
- Coded Unit class, containing data on position, value and current ownership
- Coded Empire class, containing population, economy and how they relate to size
- Coded main loop, creates many empires on different locations and allows them to grow and conquer other territories. Updates Empire population and economy every timestep.
